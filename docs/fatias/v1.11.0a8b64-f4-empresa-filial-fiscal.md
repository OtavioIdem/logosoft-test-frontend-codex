aceita e que a nota fiscal vai exigir, em vez de o operador descobrir a ausência
na hora de emitir.

## 4. Armadilhas conhecidas desta fatia

1. **O Swagger mente na anulabilidade, pela terceira vez nesta onda.** Ele
   declara os oito campos de `DefinirEnderecoFiscalRequest` como
   `string | null`. O fonte diz outra coisa:

   ```csharp
   string Logradouro, string Numero, string? Complemento,
   string Bairro, string Cidade, string Uf, string Cep,
   string? CodigoMunicipioIbge = null
   ```

   **Seis obrigatórios, dois anuláveis.** Planejar pelo Swagger nasceria com
   seis campos opcionais e o backend gravando vazio — `DEFAULT_SILENCIOSO` novo,
   a classe que a `c3` acabou de fechar.

2. **Request e response não usam a mesma chave de município.** O request manda
   `codigoMunicipioIbge` (**string**, o código IBGE); o response devolve
   `municipioIbgeId` (**Guid**). Não dá para devolver ao formulário o que veio
   do response e reenviar: é preciso resolver pelo catálogo. Quem tratar os dois
   como o mesmo campo cria um `DESCARTE` silencioso.

3. **Limpar o município é operação própria.** Existe
   `DELETE /api/administracao/{empresas|filiais}/{id}/endereco-fiscal/municipio`.
   Não se apaga município mandando `codigoMunicipioIbge: null` no PUT — isso é
   suposição sobre semântica que o backend não declarou.

4. **`crt` é anulável e não tem zero.** `Crt?` com valores `1`, `2`, `3`. Ao
   contrário de `RegimeTributario`, que começa em `0`. Enum no wire é **número**
   — não repita a confusão que custou uma reversão nesta sessão: a coluna de
   texto no banco é `HasConversion<string>()` do EF, persistência, não
   serialização.

5. **`contribuinteIpi` no PUT é `bool?`, e `null` significa "mantém".** O
   backend o tornou anulável de propósito, com comentário explícito no record
   (contrato `:2332`), porque o default `false` resetava em silêncio o indicador
   de IPI. Mandar `false` quando o operador não tocou no campo reintroduz
   exatamente o defeito que a `c3` fechou em `regimeTributario`.

6. **Os catálogos são paginados.** `/api/fiscal/cadastros/uf` aceita `termo` e
   `ativo`; `/api/fiscal/cadastros/municipios` aceita `ufSigla`, `termo`,
   `codigoIbge`, `ativo`, `pagina`, `tamanhoPagina`. Município filtra por UF —
   sem UF escolhida, não se lista município. D52: busca no servidor com debounce,
   nunca catálogo inteiro em dropdown.

7. **`EstaCompleto` vem do backend.** Não recalcule no frontend qual endereço
   está completo; o response já diz.

## 6. Blocos de trabalho

### Bloco A — `designer-ux-erp`

`uiPattern: true`: o bloco de endereço fiscal serve Empresa **e** Filial, então
nasce componente compartilhado. Definir densidade, ordem dos campos (CEP antes
ou depois de logradouro), como UF e município se encadeiam, e como
`EstaCompleto` aparece sem virar alarme.

- **Arquivos**: `features/administracao/components/**`, `styles/**`.

### Bloco B — `dev-senior-react`

- **Arquivos**: `features/administracao/{types,schemas,api,hooks,components}/**`.
- `crt` no criar e no atualizar; `contribuinteIpi` **só** quando o operador
  mexer (armadilha 5); o bloco de endereço nas duas telas; o `DELETE` do
  município como ação própria.
- **Não tocar**: `features/fiscal/**` (os catálogos são consumidos, não
  alterados), `types/erp.ts`, `lib/security/**`, `layout/**`, `scripts/**`,
  `tests/**`.

### Bloco C — `engenheiro-testes`

- Testes de payload de AC-1, AC-5 e AC-8, sobre o **objeto enviado**.
- **AC-10 é trabalho de gate**: acrescentar `DefinirEnderecoFiscalRequest` ao
  universo de `scripts/gate-contract-request-fields.mjs` e à prova durável.
  O universo cresce de 6 para 7 recortes, e a contagem nominal de §5.1 da `c3`
  precisa continuar batendo contra `9fcda80`.

### Bloco D — `qa-revisor`

AC-4 e AC-7 se confirmam **no banco** — `erp.empresas."Crt"`,
`EnderecoFiscal_*` e `UpdatedAt` —, não por leitura de tela. Foi assim que o
falso positivo do AC-8 da `c3` foi pego.

## 7. Sequenciamento

A → B → C → D. O design vem antes porque o bloco de endereço é herdável por duas
telas. Esta fatia **não** disputa arquivo com `b62` nem `b63`.
