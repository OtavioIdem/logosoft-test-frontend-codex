# Skills de review — Codex

Estas skills definem como o Codex deve revisar, validar e decidir commit de uma versão do LogoSoft ERP Frontend.

Antes de revisar qualquer pacote, leia nesta ordem:

1. `00_papel_do_reviewer.md`
2. `01_procedimento_review.md`
3. `02_validacoes_obrigatorias.md`
4. `03_review_git_escopo.md`
5. `04_review_funcional_tela_fluxo.md`
6. `05_review_mocks_guid_fiscal.md`
7. `06_criterios_commit_bloqueio.md`
8. `07_modelo_relatorio_bloqueio.md`

O objetivo do review é proteger o repositório principal, não apenas verificar se o build passa.
